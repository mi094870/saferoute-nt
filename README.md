# SafeRoute NT：用 AI 幫南投學生找到更安全的通學路線

這份專案已整理成可直接在瀏覽器開啟的靜態網頁版，並完成一輪版面、互動與瑕疵修正。
目前主題已改為南投縣學校總覽版本。

## 目前內容

- 通學安全儀表板首頁
- 南投縣官方學校名錄
- 學制篩選、搜尋與學校切換
- 通學方式、顯示模式、更新頻率控制
- 南投鄉鎮分布總覽與學校周邊細部地圖
- 即時風險分數、建議路線、近期事件與摘要卡片
- 路口監看、車流預估與路徑判斷原因面板
- 選定學校詳情區塊
- 純前端架構，方便後續自行修改

## 已修正與優化

- 修復原本亂碼與不可用的前端內容
- 將示意學校改為南投縣官方學校資料
- 補強按鈕、地圖選點、搜尋與互動流程
- 重做總覽地圖為南投鄉鎮分布視覺
- 加入地圖圖例與選定學校詳情面板
- 加入設定保存，重新整理後會保留目前選項
- 改善 RWD 響應式版面與視覺層次
- 補上空資料與邊界情況處理
- 補上本機伺服器啟動腳本，避免 `file://` 模式擋住底圖與定位
- 補上 localhost 自動熱更新，修檔後可自動刷新測試頁
- 定位改為持續追蹤更新，可依不同使用者目前位置重新估算
- 風險分數改為受時間、天氣、定位距離、學校特性、通學方式與顯示模式共同影響
- 地圖與細部動線改為非直線路徑，會依模式切換不同路徑邏輯
- 路線改為優先使用實際道路路網，抓不到時才退回模擬備援

## 如何開啟

如果你只是想快速看版面，可以直接打開 `index.html`。

但如果你要正常使用：

- 地圖底圖
- 使用者定位權限
- 依不同使用者位置估算距離與時間

請優先使用 `start-localhost.bat`。

它會自動用本機伺服器開啟專案，網址會是：

```text
http://127.0.0.1:8123/index.html
```

如果你想自己手動啟動，也可以執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve-local.ps1 -Port 8123 -OpenBrowser
```

## 檔案分工

- `index.html`：版面結構與元件
- `styles.css`：顏色、排版、RWD 響應式樣式
- `school-data.js`：南投縣學校資料
- `app.js`：互動邏輯、地圖顯示、定位權限、狀態保存與儀表板更新
- `serve-local.ps1`：Windows 免安裝本機靜態伺服器
- `start-localhost.bat`：雙擊即可開啟 localhost 版本
- `app-config.js`：地圖底圖、路徑服務與本機熱更新設定
- `refresh-browser.ps1`：本機測試時可嘗試刷新目前可見的瀏覽器頁面

## 你之後可以怎麼改

- 想改版面：改 `index.html` 和 `styles.css`
- 想改功能：改 `app.js`
- 想換學校資料：改 `school-data.js`
- 想換事件或模擬資料：改 `app.js` 裡的 `recentAccidents`、`weatherStates`
- 想串接真實資料：把 `app.js` 的示範資料改成 API `fetch()` 即可
- 想換路徑或地圖服務：改 `app-config.js`

## 網頁版之後還能不能繼續修

可以。

這份目前是標準的 HTML + CSS + JavaScript 網頁版，所以你之後如果發現：

- 版面要微調
- 某段邏輯要修正
- 學校資料要更新
- 想串接真正 API

都可以直接修改原始檔，重新整理頁面就會看到結果。

如果之後部署到正式網站，也是改完檔案再重新上傳新版即可。

## 備註

學校名錄已改採南投縣官方開放資料整理；交通風險與事件仍以可維護的前端邏輯模擬。
目前路徑已可優先抓公開道路路網，但若要正式給大量使用者長期使用，建議把 `app-config.js` 內的路徑服務換成你自己的 Directions API 或商用地圖服務。
